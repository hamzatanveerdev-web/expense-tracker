# Expense Tracker

A modern expense tracking application that helps users manage their income, expenses, and financial activities in one place.

## 🚀 Features

* Add, edit, and delete expenses
* Track income and expenses
* View financial summaries
* Responsive and user-friendly interface
* Real-time balance calculation
* Expense categorization

## 🛠️ Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* Tailwind CSS

## 🎯 Purpose

This project was built to help users monitor their spending habits, manage budgets, and gain better control over their personal finances.
